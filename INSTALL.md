# Установка Drova for Mac

## Загрузка

[Скачать DMG · 1.0.7](https://github.com/HooMDooM/DrovaMac/releases/latest/download/Drova-macOS-universal.dmg) · [Скачать ZIP · 1.0.7](https://github.com/HooMDooM/DrovaMac/releases/latest/download/Drova-macOS-universal.zip)

Требуется macOS 14+. В обоих файлах — одно Universal-приложение для Apple Silicon и Intel. Xcode не нужен.

## Установка из DMG

1. Откройте скачанный образ.
2. Перенесите **Drova.app** на значок **Applications**.
3. Извлеките образ и запустите Drova из папки **Программы**.

Для ZIP: распакуйте архив и перенесите Drova.app в «Программы».

## Первый запуск

Текущий выпуск подписан сертификатом **Developer ID Application** и прошёл **нотаризацию Apple**. Нотариальный билет прикреплён к приложению; проверка Gatekeeper пройдена.

При обычном первом запуске macOS может спросить, хотите ли вы открыть приложение, загруженное из интернета. Подтвердите открытие. Отключать Gatekeeper или снимать карантин через Терминал не требуется.

Если появляется предупреждение о неизвестном разработчике, проверьте, что вы скачали текущий выпуск: первоначальная версия от 16 октября была без Developer ID. Если macOS сообщает о повреждении файла, скачайте его заново и сверьте SHA-256.

## Дополнительные разрешения

- **Геопозиция** запрашивается при нажатии «Определить» в выборе своего города. Город можно указать вручную.
- **Уведомления** запрашиваются при включении наблюдения за станцией через колокольчик.
- Если используется LuLu или другой сетевой фильтр, разрешите Drova соединения с сервисом и выбранной игровой станцией.

## Вход и игра

Войдите через почту и пароль Drova либо вкладку **«Код с устройства»**, подтвердив код на сайте. Вход по токену предназначен для опытных пользователей.

Выберите игру, город и станцию. Для начала подойдут H.264, 1080p и 20 Мбит/с. При нестабильной сети снизьте битрейт или разрешение, увеличьте аудиобуфер.

Для сервиса нужен аккаунт и доступное игровое время. Тарифы и наличие станций определяет Drova; некоторые игры требуют вашей лицензии в игровом магазине.

## Управление сессией

- **Дважды Esc** — освободить мышь; клик по изображению — захватить снова.
- **⌘L** — отметить момент лага в журнале трансляции.
- **«Идёт трансляция» → «Открыть окно»** в боковой панели — вернуть скрывшееся окно игры.
- **⌘W → Завершить** — закончить игровую сессию на станции.
- **⌘W → Отключиться** — закрыть трансляцию без команды завершения игры.
- **«Держать сессию после „Отключиться“»** в настройках — поддерживать сессию без трансляции, например для Parsec. Настройка выключена по умолчанию и действует, пока Drova открыта. **Игровое время продолжает оплачиваться до завершения сессии.**

## Проверка загрузки

Скачайте **SHA256SUMS.txt** из того же выпуска и положите рядом с архивом. В Терминале в этой папке выполните:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```

Для скачанного файла должно появиться **OK**. SHA-256 проверяет целостность загрузки. Приложение также имеет подпись Developer ID.

## Обновление

Завершите игру, закройте Drova и замените приложение новым выпуском. Настройки сохраняются отдельно. Автообновления нет.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Не запускается | macOS 14+, целостность загрузки, подтверждение первого запуска |
| Ошибка входа | Вход на drova.io и другой способ авторизации |
| Каталог не загружается | Доступ к интернету; разрешение Drova в LuLu или другом сетевом фильтре |
| Нет станций | Город, фильтры, наличие выбранной игры |
| Нет звука | ⌘M и системное устройство вывода |
| Рывки | Ethernet, меньший битрейт, другой аудиобуфер; отметьте лаг по ⌘L и откройте «Настройки → Журналы трансляций» |
| Не видно курсор после переподключения | Для рабочего стола включите «Курсор всегда виден»; в шутерах оставляйте эту настройку выключенной |
| Кодек недоступен | Аппаратная поддержка Mac |
| Мышь захвачена | Дважды Esc |

Журналы трансляций находятся в `~/Library/Logs/DrovaMac`; сохраняются 20 последних файлов. В них записываются название игры, идентификатор станции, настройки и показатели трансляции. Перед публикацией просмотрите файл и скройте данные, которыми не хотите делиться.

[Сообщить о проблеме](https://github.com/HooMDooM/DrovaMac/issues/new/choose). Укажите macOS, модель Mac, кодек, версию клиента и шаги повторения. Скройте личные данные на материалах.

## Удаление

Завершите сессию, выйдите из аккаунта, закройте приложение и переместите Drova.app в Корзину. [Расположение локальных данных](PRIVACY.md).
