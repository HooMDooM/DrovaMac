# Локальные данные и соединения

Описание выпуска 1.0.0.

## Вход

При входе через почту и пароль они отправляются Drova по HTTPS. При входе по коду подтверждение выполняется на сайте сервиса. Пароль не сохраняется приложением.

Токен входа хранится в `~/Library/Application Support/DrovaMac/authToken` с правами файла `600`. Это файл, а не зашифрованное хранилище Keychain: процессы вашего пользователя macOS могут иметь к нему доступ. Выход из аккаунта удаляет токен.

Настройки, город и последняя игровая сессия хранятся в пользовательских настройках macOS для `local.drova.mac`. Данные последней сессии могут содержать идентификатор и токен подключения.

## Сеть

Клиент обращается к `drova.io`, `services.drova.io`, адресам изображений каталога и выбранной станции. Для входа по коду передаются сведения об устройстве, включая локальное имя Mac и версию системы. Видео, звук и ввод используют протокол станции Drova.

Технические сообщения записываются в системный журнал macOS. Перед публикацией журналов следует скрыть личные данные, токены, идентификаторы сессии и адреса частных станций.

Условия обработки данных самим сервисом доступны на [drova.io](https://drova.io).

## Публикуемые файлы

Репозиторий содержит документацию и скриншоты; Releases — готовое приложение и контрольные суммы. Данные входа, настройки пользователя, исходники и локальные журналы в опубликованные файлы не включены.
